xIVISION Theme — Odoo 19 Enterprise

Identidade visual ExcelVision para o backend e frontend do Odoo

O que faz este módulo?

Aplica o Design System oficial da ExcelVision (xIVISION) ao Odoo 19 Enterprise — cores, tipografia e identidade visual — sem modificar nenhum ficheiro core do Odoo.

  • Paleta de azuis ExcelVision em todos os elementos do backend
  • Navbar, menu lateral e botões na cor institucional
  • Estilos de formulários, kanban e portal consistentes com a marca
  • Compatível com Odoo 19 Enterprise Cloud (não-SH)
  • Instalação via repositório Git privado ou App Store

Instalação

  1. Ligar o repositório Git privado à instância Odoo Cloud em Definições → Aplicações de terceiros
  2. Atualizar a lista de aplicações
  3. Pesquisar xIVISION e clicar em Instalar
